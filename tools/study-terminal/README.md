# 학습 터미널 공유 유틸

오른쪽 터미널의 명령 실행 결과를 파일로 기록하여, 내용을 대화창에 복사하지 않고도 Codex가 확인할 수 있게 합니다. 키보드로 입력한 명령문 자체는 기록하지 않는 출력 전용 방식입니다.

## 빠른 시작

최초 한 번 설치하면 어느 디렉터리에서든 짧은 명령으로 시작할 수 있습니다.

```bash
./tools/study-terminal/install.sh
study
```

`[study] recording started`와 `[study]$`가 표시되면 학습 명령어를 한 줄씩 실행합니다. 실행을 마친 뒤 Codex에 **`했어`**라고만 알려주면 됩니다. `cd`, 환경 변수 설정 등 현재 셸의 상태도 세션 동안 유지됩니다.

기록을 끝낼 때는 다음 명령을 실행합니다.

```bash
exit
```

자주 사용하는 명령은 다음과 같습니다.

```bash
study          # 학습 터미널 시작
study status   # 임시 출력 기록 상태 확인
study clear    # 임시 출력 기록 삭제
study help     # 사용법 표시
```

## 저장 위치와 GitHub 보호

실제 기록은 Git 저장소 밖의 다음 임시 디렉터리에 저장됩니다.

```text
/tmp/devops-learning-terminal/
```

따라서 `git add .`을 실행해도 기록이 저장소에 포함되지 않습니다. 추가 방어를 위해 `.gitignore`에도 로그 및 로컬 기록 패턴을 등록했습니다.

임시 기록을 바로 삭제하려면 다음을 실행합니다.

```bash
study clear
```

`/tmp`의 파일은 운영체제를 재시작하거나 시스템이 임시 파일을 정리할 때 사라질 수 있습니다. 장기 보관할 학습 내용은 Codex가 민감한 정보를 제외하고 정리한 문서만 GitHub에 커밋합니다.

## 토큰 사용량 절약 방식

Codex는 내부 확인용 `read-new.sh`를 통해 이전 확인 이후 새로 추가된 출력만 읽습니다. 새 출력이 32 KiB를 넘으면 전체를 읽지 않고 처음 8 KiB와 마지막 24 KiB만 확인하며, 중간 부분이 생략됐음을 표시합니다.

명령 하나가 매우 긴 결과를 내는 경우에는 처음부터 다음처럼 범위를 줄이는 것이 좋습니다.

```bash
command | head -n 100
command | tail -n 100
command 2>&1 | less
```

## 보안 주의사항

기본 스크립트는 일반 터미널 전체를 녹화하지 않습니다. 명령을 먼저 입력받은 다음 그 명령의 표준 출력과 표준 오류만 별도로 기록하므로, 입력한 명령문과 일반적인 비밀번호 프롬프트의 입력값은 로그에 포함되지 않습니다.

다만 프로그램이 비밀 값을 **화면에 출력**하면 그 출력은 로그에 남을 수 있습니다. 다음 값이 출력되는 명령은 실행하지 않습니다.

- 비밀번호
- API 키와 접근 토큰
- SSH 개인 키
- 개인정보 및 업무상 비밀

민감한 출력이 의심되면 즉시 세션을 `exit`으로 종료하고 `clear.sh`로 임시 기록을 삭제합니다. 공개 학습 문서에는 원본 로그가 아닌 검토·정리된 내용만 저장합니다.

이 유틸은 한 줄 단위 학습 명령에 맞춰져 있습니다. `vim`, `top`처럼 화면 전체를 제어하는 프로그램이나 여러 줄 대화형 프로그램은 기록 세션 밖에서 실행합니다.
