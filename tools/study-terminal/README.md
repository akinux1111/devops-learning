# 학습 터미널 공유 유틸

오른쪽 터미널에서 실행한 명령과 출력을 파일로 기록하여, 내용을 대화창에 복사하지 않고도 Codex가 확인할 수 있게 합니다.

## 빠른 시작

저장소 최상위 디렉터리에서 실행합니다.

```bash
./tools/study-terminal/start.sh
```

`[study] recording started`가 표시되면 같은 터미널에서 학습 명령어를 평소처럼 실행합니다. 실행을 마친 뒤 Codex에 **`했어`**라고만 알려주면 됩니다.

기록을 끝낼 때는 다음 명령을 실행합니다.

```bash
exit
```

## 저장 위치와 GitHub 보호

실제 기록은 Git 저장소 밖의 다음 임시 디렉터리에 저장됩니다.

```text
/tmp/devops-learning-terminal/
```

따라서 `git add .`을 실행해도 기록이 저장소에 포함되지 않습니다. 추가 방어를 위해 `.gitignore`에도 로그 및 로컬 기록 패턴을 등록했습니다.

임시 기록을 바로 삭제하려면 다음을 실행합니다.

```bash
./tools/study-terminal/clear.sh
```

`/tmp`의 파일은 운영체제를 재시작하거나 시스템이 임시 파일을 정리할 때 사라질 수 있습니다. 장기 보관할 학습 내용은 Codex가 민감한 정보를 제외하고 정리한 문서만 GitHub에 커밋합니다.

## 토큰 사용량 절약 방식

Codex는 내부 확인용 `read-new.sh`를 통해 이전 확인 이후 새로 추가된 출력만 읽습니다. 새 출력이 32 KiB를 넘으면 전체를 읽지 않고 처음 8 KiB와 마지막 24 KiB만 확인하며, 중간 부분이 생략됐음을 표시합니다.

명령 하나가 매우 긴 결과를 내는 경우에는 처음부터 다음처럼 범위를 줄이는 것이 좋습니다.

```bash
command | head -n 100
command | tail -n 100
command 2>&1 | less
```

## 보안 주의사항

기록 세션에서는 다음 값을 직접 입력하거나 출력하지 않습니다.

- 비밀번호
- API 키와 접근 토큰
- SSH 개인 키
- 개인정보 및 업무상 비밀

비밀번호 입력이 필요한 작업은 먼저 `exit`으로 기록을 종료한 뒤 별도 터미널에서 처리합니다.
